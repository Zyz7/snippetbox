# Dashboard

<img width="1400" height="843" alt="screen113207" src="https://github.com/user-attachments/assets/19cb72b5-fc55-4468-9230-922328ea6b36" />

It is an application that has user registration and login. It is used to save phrases, edit them or modify them. 
Those who do not register their username can only read the phrases. The project is based on a book by Alex Edwards.

## languages used

- css3
- html5
- golang
- mysql

## tools used

- **[render](https://render.com/)**
- **[boxicons](https://boxicons.com/)**
- **[db4free](https://www.db4free.net/index.php?language=es)**
- **[Let's Go](https://lets-go.alexedwards.net/)**
