About


  Go is a concurrent programming language compiled with static typing inspired by C 
  syntax, but with memory security and garbage collection. It has been developed by 
  Google and its initial designers were Robert Griesemer, Rob Pike and Ken Thompson.
  It is currently available in binary format for Windows, GNU/Linux, FreeBSD and 
  Mac OS X operating systems, and can also be installed on these and other systems 
  using the source code. Go is a language compiled, concurrent, imperative, 
  structured, and object-oriented programming which is currently available for 
  different types of Unix-like systems, including Linux, FreeBSD, Mac OS X, and 
  Plan 9 (since part of the compiler is based on a previous work on the Inferno 
  operating system). The supported architectures are i386, amd64 and ARM.
